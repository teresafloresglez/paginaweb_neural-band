# Meta Neural Band · Interacción persona-ordenador

Trabajo de la asignatura **Fundamentos de Interacción Persona-Ordenador**.

Página web sobre la **Meta Neural Band**, una pulsera de electromiografía (sEMG) que convierte la intención de mover los dedos en órdenes para el ordenador. Presentada por Meta en septiembre de 2025, sirve de mando para las gafas Meta Ray-Ban Display.

## Qué incluye la web

- Qué es el dispositivo y por qué lo he elegido, con sus beneficios para la IPO.
- Cómo funciona, paso a paso.
- Fotos del dispositivo.
- Su evolución: teclado, ratón, pantalla táctil, gestos por cámara, voz y la pulsera Myo.
- Tabla comparativa de dispositivos de entrada.
- Limitaciones y enlaces para ampliar información.

## Estructura

````
index.html      Documento HTML único
css/style.css   Hoja de estilos única
img/            Fotografías
````

Está hecha solo con HTML y CSS, sin JavaScript.

## Créditos

Las imágenes pertenecen a Meta y se usan solo con fines docentes. Las fuentes de información están enlazadas al final de la propia web.
